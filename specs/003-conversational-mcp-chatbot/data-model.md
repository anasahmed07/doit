# Data Model: Conversational MCP Chatbot

**Date**: 2026-02-08
**Feature**: 003-conversational-mcp-chatbot

## New Entities

### Conversation

Persisted in the shared PostgreSQL database. Represents a chat session.

| Field        | Type              | Constraints                     | Notes                                |
| ------------ | ----------------- | ------------------------------- | ------------------------------------ |
| id           | UUID              | PK, default uuid4               |                                      |
| user_id      | UUID              | NOT NULL, indexed                | FK conceptual to `user.id`           |
| title        | str (nullable)    | max 200 chars                    | Auto-generated by LLM from 1st msg   |
| created_at   | datetime          | default utcnow                   |                                      |
| updated_at   | datetime          | default utcnow                   | Updated on new message               |

**SQLModel definition** (in `backend/src/backend/models/conversation.py`):
```python
class Conversation(SQLModel, table=True):
    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    user_id: uuid.UUID = Field(index=True)
    title: Optional[str] = None
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)

    messages: List["Message"] = Relationship(
        back_populates="conversation",
        sa_relationship_kwargs={"cascade": "all, delete-orphan"}
    )
```

### Message

Persisted in the shared PostgreSQL database. A single exchange in a conversation.

| Field            | Type     | Constraints                          | Notes                    |
| ---------------- | -------- | ------------------------------------ | ------------------------ |
| id               | UUID     | PK, default uuid4                     |                          |
| conversation_id  | UUID     | NOT NULL, FK to conversation.id, indexed |                       |
| role             | str      | NOT NULL, enum: "user", "assistant"   |                          |
| content          | text     | NOT NULL                              | Markdown for assistant   |
| created_at       | datetime | default utcnow                        |                          |

**SQLModel definition** (in `backend/src/backend/models/conversation.py`):
```python
class Message(SQLModel, table=True):
    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    conversation_id: uuid.UUID = Field(foreign_key="conversation.id", index=True)
    role: str  # "user" or "assistant"
    content: str
    created_at: datetime = Field(default_factory=datetime.utcnow)

    conversation: Optional["Conversation"] = Relationship(back_populates="messages")
```

## Existing Entities (Referenced by MCP Tools)

These are NOT modified. The MCP server reads/writes them directly via SQLModel.

### User
- `id` (UUID, PK), `email` (str, unique), `name` (str?), `image` (str?), `created_at`

### Project
- `id` (UUID, PK), `user_id` (UUID), `name` (str), `framework` (str, default "KANBAN_FIXED"), `created_at`

### ProjectTask
- `id` (UUID, PK), `project_id` (UUID, FK), `status` (str: TODO/IN_PROGRESS/DONE), `priority` (str: LOW/MEDIUM/HIGH), `due_date` (datetime?), `content` (str), `order_index` (float), `assignee_id` (UUID?), `created_at`, `updated_at`

### Note
- `id` (UUID, PK), `user_id` (UUID), `category_id` (UUID?, FK), `title` (str?), `content` (str?), `order_index` (float), `created_at`, `updated_at`

### Category
- `id` (UUID, PK), `user_id` (UUID), `name` (str), `color` (str, default "#000000"), `created_at`

### Session (Better Auth)
- `id` (UUID, PK), `token` (str, indexed), `userId` (UUID), `expiresAt` (datetime)
