# DoIt - Full-Stack Task Management Application

## Project Overview

DoIt is a comprehensive full-stack web application designed to transform how individuals and teams manage their tasks and projects. Building upon the foundation of a single-user CLI application, DoIt evolves into a feature-rich platform that combines personal task management with professional project workflows, all wrapped in an intuitive and beautiful user interface.

## Vision & Purpose

DoIt bridges the gap between simple to-do lists and complex project management tools. It empowers users to seamlessly manage everything from daily personal tasks to sophisticated team-based projects, all within a single, cohesive platform. Whether you're an individual tracking personal goals or a team executing agile sprints, DoIt adapts to your workflow.

## Core Functionality

### Task Management Foundation

At its heart, DoIt provides comprehensive task management capabilities that allow users to create, organize, and track tasks with ease. Users can manage both personal todos and project-based tasks, ensuring nothing falls through the cracks whether at home or at work.

### Workflow Flexibility

DoIt supports multiple project management methodologies to accommodate diverse working styles:

- **Kanban (Default)** - Visual workflow management with customizable boards and columns for streamlined task progression
- **Scrum** - Sprint-based planning with backlogs, sprint boards, and velocity tracking for agile teams
- **Agile** - Iterative development support with user stories, epics, and continuous delivery frameworks
- **General Todos** - Simple list-based management for personal tasks and quick captures

### Smart Organization

DoIt provides powerful organizational tools to keep tasks manageable:

- **Priority Levels** - Assign high, medium, or low priority to focus on what matters most
- **Tags & Categories** - Flexible labeling system (work, home, personal, etc.) for contextual organization
- **Search Functionality** - Quick keyword search across all tasks and projects
- **Advanced Filtering** - Filter tasks by status, priority, due date, tags, or custom criteria
- **Intelligent Sorting** - Reorder tasks by due date, priority, alphabetically, or custom arrangements

DoIt is built as a modern full-stack web application featuring:

- **Frontend** - Rich, interactive user interface with real-time updates
- **Backend** - Robust API and business logic layer
- **Database** - Persistent storage for users, tasks, projects, and configurations
- **Authentication** - Secure user management and session handling
